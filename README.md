# MZOBS AI Interview

AI-powered, resume- and job-description-aware interviews for MZOBS.

## Planned capabilities
- 15-minute structured interviews
- Live voice/video and recorded interview modes
- Adaptive follow-up questions grounded in candidate answers
- Employer reports with question-level evidence, strengths, skill gaps, and a review recommendation
- Recording consent and privacy-first handling

## Local setup
1. Install Node.js 20+.
2. Install dependencies with `npm install`.
3. Copy `.env.example` to `.env.local`.
4. Set `XAI_API_KEY` in `.env.local`.
5. Start the app with `npm run dev`.

Never commit API keys, candidate resumes, or interview recordings.
